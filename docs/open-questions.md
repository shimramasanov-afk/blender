# Открытые вопросы

Неизвестность не заполняется догадкой. Если она ломает внешнюю интеграцию — вопрос задаётся до зависимой работы. Обратимую деталь стенда можно выбрать и записать в [decisions.md](decisions.md).

| ID | Неизвестно | От какого этапа зависит | Блокирует текущую работу |
|---|---|---|---|
| Q1 | Точная игра и версия клиента | адаптер, калибровка, боевой цикл | Lineage 2 Interlude (чат F44). Сборка / ревизия unknown. Полосы размечены на одном layout (F45), не на всех раскладках. Блокирует S4, не этап 1 |
| Q2 | Способ запуска клиента | адаптер, длинный прогон с окном | выбран: Parallels Desktop + Windows, клиент в окне хоста. Видимое окно `Windows 11` снято (F40). Скрытый стол гостя не источник |
| Q3 | Разрешённый способ ввода | InputBackend, dry-run→live | вариант A работает: live в Notepad без `L2.exe` (F43). `DryRunInputBackend` по-прежнему без live |
| Q4 | Есть ли разрешённая телеметрия | `TelemetrySource`, бой | стенд: `sim_ground_truth` (F35). `ui_vision` в S4: F51 дельта цели 0.444→0.366. Живого кулдауна-спирали нет |
| Q5 | Семантика камеры и движения в игре | калибровка, навигация в клиенте | F79: один тап стрелки ≈40 px, 146/113 инлаеров, ratio ≥0.70. Профиль нет (`|dx|<50`). Мышь→px не константа (F78). Метры / GT yaw unknown. Не закрыт |
| Q6 | Разрешён ли тестовый сервер и какой | боевой цикл | да: `LineageII Interlude Server`, BotEbaniy, говорящий остров. S4-зонд F49 на этом стенде. Не локальный L2J |
| Q7 | Выдано ли разрешение записи экрана для нашего зонда | замер захвата | для `capture-probe` на этой машине: granted (preflight, без запроса). Другой бинарник — снова unknown |
| Q8 | Поддерживает ли выбранный GPU-путь нужные операции | MPS/Metal | нет; ускорение не начинать до ответа |
| Q9 | Канал кадра Swift→Python | склейка захвата с петлёй | закрыт: stdout pipe `L2F1`. Shared memory не выбран |
| Q10 | Нужен ли отдельный проверщик типов | регулярная правка контрактов | нет |
| Q11 | Как получить ненулевые GT-окна застревания на стенде | оценка восстановления, H16 | нет; текущий каталог их не даёт |

Текущая работа (инструкции и локальный стенд) может идти при `unknown` в Q1–Q6.

Когда ответ появляется, строка обновляется и, если это выбор, добавляется запись в [decisions.md](decisions.md). Гипотезы с метриками — в [assumptions.md](assumptions.md), не сюда.
