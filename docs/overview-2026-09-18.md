## 1. Что это за проект

Исследовательский **сенсомоторный агент**: кадр окна → признаки →
контроллер → моторное намерение → легальный ввод на хосте.
Не скрипт по карте, не разбор пакетов, не готовый бот.

Целевая машина: Apple M4 Max. Игра на стенде: Lineage 2 Interlude
в окне Parallels (`Windows 11`), сервер `LineageII Interlude Server`,
персонаж BotEbaniy, Talking Island (F48). Сборка клиента unknown (Q1).

Биологическое сходство (SNN, MaleCNS) **не** доказывает качество
управления. MaleCNS — коннектом дрозофилы, не игровая политика (F5).

Запрещено и не делалось: обход античита, инъекции, скрытие ввода,
патчинг клиента, перехват учёток, автономный фарм.

## 3. Архитектура

Три стека. Их нельзя смешивать в одном отчёте и нельзя подменять
друг другом.

```text
Стенд S0                          Контур Circuit                      Живой зонд
types.Observation                 contracts.Frame                     SCK кадр
        │                                  │                                 │
        ▼                                  ▼                                 ▼
   ControlLoop                      VisualEncoder                      HUDParser
        │                                  │                           (+ опц. L1)
        ▼                                  ▼                                 │
  types.Action                      MotorIntent                              ▼
        │                                  │                          CGEvent HID
        ▼                                  ▼                           короткий
  SyntheticEnv                        Command                          сценарий
                                   Mock / не CGEvent
```

### 3.1 Стенд

Вход политики — только кадр. Координаты агента, HP, стены — в отчёт
(`StepInfo`), не в контроллер.

Три учебные политики на `SyntheticEnv`: `reactive`, `recurrent`, `snn`.
Это не живой L1.

Отдельный nav-sim: `SimulationEnvironment` + `BaselineController`
(`baseline_memory_v1`). Канон приёмки — 60 эпизодов, seed=0, **52/60**.
Восемь незакрытых сцен законсервированы (ADR-0030). Пакет `sim/` и
эти веса **не ретюнить**.

### 3.2 Контур `Circuit`

```text
FrameSource → Frame
TelemetrySource → события
        → VisualEncoder → contracts.Observation
        → CircuitController → MotorIntent
        → ActionDecoder → Command
        → InputBackend → Effect
```

`build_mock_circuit` — искусственные кадры.
`build_sck_circuit` — живой SCK и **mock** ввод (захват без HID).

Связки «SCK + CGEvent внутри `Circuit.run`» нет. Живой бой и диалог
идут через зонды, не через Circuit.

### 3.3 Живой зонд (то, чем мы реально управляли игрой)

```text
SCKGrabber (окно Parallels, без масок HUD на боевом захвате)
    → HUDParser (свои полосы, рамка цели, EntityDefeated)
    → опционально NavigationEncoder + BaselineController
    → CGEventInputBackend
         live_confirmed + live_danger_confirmed
         фокус только Parallels
         F12 / потеря фокуса / watchdog 250 мс / release_all
    → сценарий: lock / F2 / F3 / Tab / Escape / /target / overlay
```

Вход — ScreenCaptureKit. Выход — CGEvent на PID консоли Parallels,
не в `L2.exe` внутри гостя. Скрытое / off-screen окно не источник.

### 3.4 Иерархия L1 / L2 / L3

| Уровень | Роль | Сейчас |
|---|---|---|
| L1 | сенсомотор, 20–60 Гц | Frozen 52/60 на стенде. В живом споте F81–F82 **L1=0** — боем рулит FSM, не замороженный контроллер |
| L2 | тактика, 2–10 Гц | синтетический `SpotAutonomousAgent`; живой `s4-integrated-spot` — отдельный FSM зонда |
| L3 | стратегия | нет. Зонд меню гида — не планировщик квестов |

### 3.5 Живой край: железо и окно

| Что | Факт |
|---|---|
| Mac-дисплей | логические **2056×1329**, Retina 2× |
| Окно Parallels | **2056×1290** под строкой меню (id недавно 16372) |
| Кадр SCK | **4112×2580** (scale 2) |
| Гость / игра | оператор: **2560×1600** |
| Сетка слотов | задана в госте 2560×1600, на окно хоста масштабируется |

Камера в клиенте: стрелки, не RMB-драг (Interlude DirectInput мышь
как yaw игнорирует). Непрерывный `w` ≥8 с — риск H17; рабочие
импульсы ≤800 мс (ADR-0064).

### 3.6 Безопасность ввода

Без двух флагов `CGEventInputBackend` не создаётся.
Живые CLI требуют `--live --danger-confirmed`.
Стоп: F12, уход фокуса, watchdog, `release_all`.
Заглушка обязана называться `mock` в имени или в логе.

## 4. Что достигнуто

### 4.1 Наука и стенд (до живой игры)

- Пустой каталог → пакет, контракты, запись сессий, CLI.
- Nav-sim валидирован как локальный стенд, не как перенос в MMORPG.
- Эвристический L1 доведён до **52/60** и заморожен (F28–F29).
- H15 (каналы энкодера дают +15% успеха) **отклонена** (Δ = +0.033).
- H16 (память чинит тупики) **не подтверждена** (ловушки 10/10 = 10/10).
- H6 (MPS/Metal меняют тик) **отклонена**. Бэкенд `numpy_cpu`.
- Песочницы SNN / GRU / синтетический MaleCNS есть. H3, H4, H11
  **не приняты**. Полный FlyEM не загружался.
- Синтетический бой и спот (F35, F39) — не клиент.

### 4.2 Сенсор и актуатор

- H7: видимое окно Parallels, ~30 FPS, drops 0 (F40).
- H8: живой p95 2.19 мс на observe+infer+idle act (F57).
- HUD Interlude размечен на одном layout: свои CP/HP/MP, рамка цели,
  смерть по HP=0 или пропаже рамки (F45–F47). Не все раскладки UI.
- Фокус через NSWorkspace, не osascript на горячем пути (F44).
- HID в Notepad подтверждён (F43), затем в игру — после явного S4.

### 4.3 Живой бой (Talking Island)

Цепочка зондов, не фарм:

| Факт | Что доказано |
|---|---|
| F49 | F1 лочит, F2 ушёл, HP цели не двинулся |
| F51 | F2 даёт дельту HP (0.444→0.366) |
| F52 | килл + F3 |
| F53 | 3 цикла, farm=false |
| F80 | L1+L2 спот **7/10**, стоп по своему HP |
| F81 | **5/5**, L1 выключен, агро-логика |
| F82 | **10/10 за 150 с**, L1=0, агро 2, разворот 2, roam 14, stuck_keys 0 |

Это не «агент не застревает» и не 95%. Это повторённый узкий навык:
F1 / удар / смерть / F3 / короткий roam, потолок 10 фрагов.

### 4.4 Движение и камера (не закрыто)

- Короткий `w` даёт поток на кадре; `stuck_detected` у энкодера
  ни разу не был true на живых прогонах.
- Непрерывный `w` ≥8 с дважды совпал со срывом сессии (F65/F66/F68).
  Позже 8 с проходили без срыва (F72). H17 открыта.
- KLT `|dx|≈0` не значит, что камера стоит (H18 принята, F75).
- Один тап стрелки ≈40 px, 113–146 инлаеров (F79). Профиль yaw
  в JSON не писали: порог `|dx|≥50` не взят. Метры неизвестны. Q5 открыт.

| Факт / ход | Что есть | Чего нет |

| F83 | F5 лочит гида | окно диалога не открылось |
| F84 | — | живой h не стартовал (окно off-screen) |
| F85 | `/target Newbie Guide` → F2 → ЛКМ (0.50, 0.48) → 6 ссылок слева, 6 кликов | OCR текста пунктов нет |
| F86 | Tab занимает слот, Escape освобождает | слот Б тогда был на фактическом инвентаре `[1592,650,342,307]`, не на целевой сетке |

## 7. Расхождение замысла и факта

Дорожная карта говорила: S1 (закрыть H1) → S2 захват → S3 ввод →
S4 один живой навык. Квесты, диалоги, инвентарь в v1 **не входили**.

Фактически оператор открыл живой край раньше закрытия H1. Это
записано: S2 открыт явной командой. Дальше пошли бой, калибровка
камеры, затем деревня.

Поэтому сейчас два разных «успеха» лежат рядом и легко путаются:

1. **Учебный v1** из `vision.md`: три контроллера на стенде, H1–H5
   решены, живой клиент ещё не обязателен.
2. **Стендовый Interlude**: персонаж уже бьёт спот и открывает гида.

Ни то ни другое не есть «агент играет в Lineage». Выбирать надо явно.

Архитектура живого боя — **не** Frozen L1. F82 выключил L1 (0 шагов
энкодера в цикле) и стабилизировал 10/10. Возвращать Frozen 52/60
в клиент — отдельное решение, не «продолжить с того же места».

## 8. Чего нет (чтобы не додумать)

- Автономный фарм, хил F4 в боевых сериях, часовой маршрут.
- Чтение квестового текста / счётчика «7/10 зубов».
- Инвентарь, вес, адена, дерево скилов, макросы — только слоты-цели
  и один живой Tab/Escape на старой стоянке инвентаря.
- Замкнутый Circuit с HID.
- Профиль yaw в `parallels_l2.json` (поле `motion` есть, канон не закрыт).
- Официальные 20 эпизодов H1–H4.
- Перенос 52/60 в игру.
- Обещание «не застревает», «успевает всегда», «античит не видит».
- F84: факта нет, прогон не стартовал.

SCK после HID иногда отдаёт `no frame`. Лечится рестартом helper /
возвратом окна на стол. Это операционный риск, не закрытая теория.

## 9. Развилки — что решать

Ниже взаимоисключающие направления. Параллелить их снова — как
последние дни: быстро, но без закрытого v1 и без посаженного UI.

### А. Остановиться и зафиксировать

Докодировать ничего. Этот файл + ADR + JSON — база.
Следующая сессия начинается с выбора B–E, не с нового зонда.

Имеет смысл, если усталость важнее темпа.

### Б. Деревня: один квестовый контур

Дожать то, ради чего ушли со спота.

Минимум: оператор сажает окна в оверлей → повтор `layout-slots`
на целевом слоте Б → гид уже умеем открывать (F85) → один пункт
меню, который ведёт к первому квесту → проверка прогресса.

Нужно решить отдельно: читаем текст (OCR) или идём по номеру
пункта, как в F85. OCR сейчас нет.

Это **выход за границы v1** (`vision.md` прямо исключает квесты).
Имеет смысл только как явный новый этап, не как «ещё один ход».

Риск: HTML разный у каждого NPC; слот А на траве даёт ложную
занятость, если эвристика слабая; SCK падает после кликов.

### В. Боевой спот: сделать его скучным и повторяемым

F82 уже 10/10 без L1. Дальше: хил, другой спот, ночь/день, другой
моб, стоп по HP оставить.

Это не закрывает Q5 и не учит деревне. Легко скатиться в фарм —
его по-прежнему нельзя открывать этим проектом.

Имеет смысл, если цель — надёжный боевой примитив для сравнения
контроллеров (тогда вернуться к H10).

### Г. Закрыть науку стенда

Официальные 20 эпизодов H1/H2 (и при желании H3/H4).
Не трогать Frozen 52/60. Не слать HID.

Имеет смысл, если снова важнее «какой контроллер вообще лучше»,
а не «что умеет BotEbaniy сегодня».

Живой бой F82 **не** заменяет эту таблицу.

### Д. Закрыть Q5 / H17, не открывая квесты

Q5: записать профиль стрелки/шага, когда пройдёт порог, или явно
отклонить «метры из пикселей» и оставить импульсы.
H17: три сессии подряд с `w`≥8 с по протоколу — принять или отклонить.

Без этого любая «пойди к маркеру на карте» — гадание.

### Е. Склеить Circuit

Один `Circuit.run`: SCK + живой CGEvent. Сейчас это сознательный
разрыв. Склейка упростит отчёты и усложнит безопасность
(легче случайно получить длинный контур).

Не делать «заодно с квестом».

## 10. Рекомендация к чтению, не к коду

Если выбирать одно направление после паузы:

1. Если хочется **понятного продукта на острове** — развилка **Б**,
   но сначала посадка окон в рамки руками (это минуты, не код).
2. Если хочется **честного v1 из vision.md** — развилка **Г**.
3. Если хочется **не ломать клиент** — не открывать 8-секундный `w`
   и не открывать фарм; H17 и запрет фарма остаются рамкой любой ветки.
4. Если непонятно — развилка **А**. Файл никуда не денется.

Я бы не начинал следующую сессию с «ещё один зонд без выбора».
Три стека, две цели (стенд vs остров) и открытые Q5/H17 уже
достаточно, чтобы разъехаться.
