## Победа только после смерти

`EntityDefeated` больше не шлётся, если рамка пропала при живом HP.

Публикуется только если:

1. рамка есть и HP перешло в 0, или
2. рамка пропала, но последнее HP ≤ 0.08 (8%).

Иначе шина даёт `TargetState(locked=false, hp_percent=None)` — это
сброс / TargetLost, не лут.

Синтетика: drop при HP 0.44 → нет `EntityDefeated`.
Пустая рамка после 0.0 → одно `EntityDefeated`, повтор нет.
Пропажа после HP 0.05 → `EntityDefeated`.
