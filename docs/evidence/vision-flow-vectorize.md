# Векторизация SAD-потока

Устройство: Apple Silicon, Python 3.14.7, numpy 2.x, CPU. Не MPS/Metal.
Контур: `NavigationEncoder` 48×32, `flow` 8×6, block=5, search=8.

Жалоба: полный frozen-прогон с `navigation_v1` занимал порядка 7–10 минут на одну руку из‑за Python-цикла SAD, не из‑за машины.

## Замер

| этап | p50 до | p50 после |
|---|---|---|
| `reference_flow` один вызов | 22.01 мс | 1.67 мс |
| `encode` при сдвиге кадра | ~35 мс (F14/зонды) | 4.08 мс |
| `scale_expansion` | 0.11 мс | не меняли |

Поля `u`/`v`/`weak` совпали с цикловым эталоном; `confidence` max abs 0.

## Решение

`keep`. Одно изменение: поиск сдвига через `sliding_window_view`, без смены сетки и порогов.
Ускорение меняет бюджет прогона H15, не тик живого клиента. Metal не включали.
