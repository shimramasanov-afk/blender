# Базовый контроллер на nav-sim-v1

Не сравнение SNN. Не перенос в MMORPG. Параметры не подбирали по held-out.

Прогон: `l2-brain baseline-eval --seed 0 --out docs/evidence/baseline-nav.json`  
Код в JSON: package 0.5.0, git dirty. Энкодер `navigation_v1`. Один seed, 60 эпизодов (12 сцен × 5 вариантов). max_steps=200.

## Гипотеза

Прозрачный контроллер без обучения на каналах `NavigationEncoder` даёт воспроизводимую базу для памяти, обучения и SNN.

Отклонение этой постановки: нет отчёта, утечка GT в политику или ветки по имени сцены. Преимущество SNN этим прогоном не проверяется (H15 открыта).

## Сводка

| | n | успех |
|---|---|---|
| все | 60 | 23 |
| training | 36 | 14 |
| validation | 12 | 5 |
| held_out | 12 | 4 |

Исходы: success 23, stuck 21, timeout 16, oscillate 0.  
Причины провала: vision 20, control 17, stale 0. У успехов cause=`none`.

`infer_ms` p50 ≈ 0.031 мс. `encode_ms` p50 ≈ 36.6 мс. Полный тик этим числом не заменяют.

| Сцена | успех | типичный исход | типичная причина |

| narrow_gate | 0/5 | timeout/stuck | control: цель видна, столкновения со створками |

Колебаний по правилу (много смен знака и длинный путь при малом сдвиге) не было. Детектор есть, на этом прогоне не сработал.

## Что это значит для следующих контроллеров

- Сенсоров достаточно, чтобы идти к видимой цели на открытом поле и при повороте только камеры.
- Обход преграды и слабая текстура ломаются уже на зрении (нет цели в признаках).
- Ворота и пропадающая цель — управление: признаки есть или недавно были, закон суммы не вывозит.
- Полезность памяти / обучения / SNN нужно показывать против этих 23/60 и таблицы сцен, не против нуля.

Маршруты под карты не добавляли.
