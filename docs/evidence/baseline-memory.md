# Кратковременная память и явное восстановление

Не биологический механизм. Не сравнение с рекуррентной реализацией. Не перенос в MMORPG. Held-out не использовали для подбора.

Прогон: `l2-brain baseline-eval --seed 0 --out docs/evidence/baseline-memory-nav.json --compare docs/evidence/baseline-nav.json`  
Код в JSON: package 0.7.0. Контроллер `baseline_memory_v1`. Энкодер `navigation_v1`. Один seed, 60 эпизодов, max_steps=200. База — F14 / `baseline-nav.json` (`baseline_v1`).

## Гипотеза

Явная кратковременная память и восстановление улучшают тупики и П-образные ловушки против `baseline_v1` без существенного ухудшения простых сцен.

Отклонение регрессии: успех на ловушках падает, либо успех простых сцен падает больше чем на 2 эпизода.  
Подтверждение улучшения: выше успех или ниже `ticks_p50` на `u_trap`+`dead_end` при тех же seed.

По сценам таблица F14 не изменилась.

## Отдельные метрики восстановления

GT-застревание = команда вперёд ≥ 0.2 и почти нет сдвига позы ≥ 8 тиков, цель дальше 0.8. Это не оптический поток.

| метрика | значение |
|---|---|
| настоящие застревания (GT окна) | 0 |
| обнаружения | 0 |
| частота обнаружения (recall) | не определена (нет GT-окон) |
| ложные срабатывания | 0 |
| восстановления | 0 |
| доля успешных восстановлений | не определена |
| время восстановления p50 | не определено |
| повторный вход в ту же ловушку | 0 |

На этом каталоге исходы `stuck` — это отсутствие прогресса к цели при ещё меняющейся позе (поиск, обход), не команда вперёд в неподвижность. Поэтому детектор восстановления ни разу не включился. Юнит-тесты на искусственном повторе структурированной сцены срабатывают; пустой повтор неба — нет.

## Что это значит

- Карты координат в политике нет.
- Отступление в v1 — разворот на месте, `forward` ∈ [0, 1].
- Критерий «статистически лучше на тупиках и U-ловушках» на seed=0 **не выполнен**: Δ успеха 0, Δ времени 0.
- Критерий «не ухудшить простые сцены» выполнен.
- Следующее сравнение — рекуррентная память против этой явной логики, либо более жёсткие ловушки, где есть GT-окна неподвижности. H15 не закрыта.
