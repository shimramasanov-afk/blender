# Ход 81: агро, жёсткий L1, серия на 5 фрагов

Дата: 2026-09-18. Frozen L1 и `sim/` не трогали. Фарм не открывали.
`tactical.py` не меняли: живой контур — `live/spot_loop.py`.
ADR-0066 не переиспользовали (уже кадр v3). Решение: ADR-0069.

## Что сделано в коде

| слой | поведение |
|---|---|
| Агро | `self_hp` упал больше чем на 0.02 и нет лока / цель без урона >2.5 с → Escape → F1 → двойной F2 |
| L1 | только COMBAT: F2 без урона >3 с и `flow_magnitude<0.01` шесть тиков; peel 350 мс, без `w` |
| ROAM | `w` 450 мс; после 3 пустых — 2×450 стрелки + 3×`w` 500 мс |
| COMBAT | автобег игры по F2, искусственный `w` не слать |
| Стоп | `kills==5` или `self_hp<0.10`. Таймаута сессии нет. F4 нет |

CLI: `l2-brain s4-integrated-spot --kills 5 --no-timeout --no-heal`.
Выход: `docs/evidence/live-s4/spot-aggro-validation.json`.

## Проверки

`pytest tests/test_spot_loop.py tests/test_s4_probe.py` — 30 зелёных.

Скриптованные факты (не клиент):

- 5 фрагов, 15×F3, `farm=false`, `timeout_s=null`, L1=0 на коротком бое;
- roam → лок → килл, без разворота;
- 15 холостых roam → 5 разворотов → `roam_limit`;
- L1 peel только после 3 с статики, `w` в COMBAT нет;
- агро: Escape → F1 → лок.
