# Исходы и события

Политика не менялась. `outcome` эпизода (success / stuck / timeout / oscillate) оставлен для сравнения с F14/F15.
`stuck` в этом поле — наследие: это не `physical_blockage`.

## Часы

| величина | значение |
|---|---|
| `tick_hz` | 20 |
| длительность тика | 0.05 с |
| `max_speed` | 0.12 **единиц за тик** (2.4 ед/с при полном forward=1) |
| `max_turn` | 0.18 рад за тик |
| `physical_blockage` | 0.40 с (8 тиков) |
| `navigation_stagnation` | 1.25 с (25 тиков) |
| `target_unobserved` / `searching` | 0.50 с (10 тиков) |
| `observation_invalid` | 0.20 с (4 тика) |

Пороги заданы в секундах, в тики переводятся через `tick_hz`. Смена частоты меняет число тиков, не смысл порога.

## Независимые признаки

| признак | GT (оценщик) | оценка контроллера (сенсоры/диагностика) |
|---|---|---|
| `physical_blockage` | команда вперёд ≥ 0.2 и сдвиг позы < 0.025 дольше 0.40 с | `situation=blocked` или `recovering` |
| `navigation_stagnation` | дистанция до цели не упала на 0.12 за 1.25 с | нет (нужна цель в GT) |
| `target_unobserved` | цель скрыта или вне FOV дольше 0.50 с | низкая уверенность пятна, не координаты |
| `searching` | — | `reason=search` или `situation=camera_turn` |
| `observation_invalid` | дроп / stale дольше 0.20 с | `reason=stale` |
| `episode_timeout` | бюджет исчерпан и цель не достигнута | — |

Признаки пересекаются. Recall и время восстановления при нуле GT-окон блокировки — `null` (N/A), не 0.

GT в рабочую политику не подаётся.
