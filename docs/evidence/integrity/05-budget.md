# Временной бюджет

Единицы (не менялись):

| величина | значение |
|---|---|
| тик наблюдения и действия | один и тот же, `tick_hz=20` |
| длительность тика | 0.05 с |
| шаг физики | 1 тик |
| `max_speed` | 0.12 единиц **за тик** (2.4 ед/с при forward=1) |
| круиз политики | 0.62 → 0.0744 ед/тик |
| `max_turn` | 0.18 рад/тик |

Нижняя граница: прямая дистанция / (cruise × max_speed) + тики на разворот к цели.
Назначенный бюджет = граница × 2.0 (запас на поиск и обход). Назначен **до** автономного успеха на новых сценах.

Замороженный каталог F14/F15 остаётся на 200 тиках. У нескольких сцен назначенный бюджет **выше** 200 (коридор 236, ворота 212, обход 208). Это ограничение старого прогона, не улучшение контроллера.

Полная таблица: `docs/evidence/integrity/budgets.json`.

На `suite=integrity` бюджет по умолчанию пока 200 (как `SimConfig`). Поднимать его можно только с пометкой «изменение стенда», отдельно от метрик контроллера. Пока не поднимали.
