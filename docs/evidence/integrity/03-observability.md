# Наблюдаемость задач

GT и лучи только в оценщике. Координаты в политику не передавались.
`GroundTruth.goal_visible` — флаг сценария (цель не спрятана), **не** видимость пикселя. Ниже — 2D LOS + FOV с места старта и после поворота на месте.

Прогон: `report_catalog(0)` → `docs/evidence/integrity/observability.json`.

## По сценам (5 вариантов, геометрия одинакова по классу)

| сцена | класс задачи | цель в FOV на старте | LOS на старте | видна после поворота на месте | исследование | память пеленга уместна |
|---|---|---|---|---|---|---|
| open_goal | visible_goal | да | да | да | нет | да |
| camera_spin | visible_goal | да | да | да | нет | да |
| latency_drops | visible_goal | да | да | да | нет | да |
| narrow_gate | visible_goal | да | да | да | нет | да |
| corridor | visible_goal | да | да | да | нет | да |
| moving_target | moves_out_of_view | да | да | да | нет | да, без модели движения — не требовать точный прогноз |
| vanishing_target | observed_then_hidden | да | да | да | нет | да, пока оценка жива |
| u_trap | visible_goal | нет | да | да | нет | после первого оборота |
| dead_end | visible_goal | нет | да | да | нет | после первого оборота |
| single_obstacle | never_observed_from_start | да (угол) | нет | нет | да | нет: стороны обхода заранее нет |
| long_fence | never_observed_from_start | да | нет | нет | да | нет |
| weak_texture | never_observed_from_start | да | нет | нет | да | нет; плюс слабое пятно |

## Следствия

`u_trap` / `dead_end` проверяют **поворот к цели, которая уже имеет LOS**, не выход после физической блокировки.
`single_obstacle` / `long_fence` / `weak_texture` — исследование: правильной стороны обхода на старте нет. Оценивать как exploration при достаточном бюджете, не как следование неизвестному пеленгу.
`narrow_gate` и `corridor` геометрически видимы. Провал corridor в F14 — детектор, не «цели нет в мире». Провал ворот — управление при видимой цели.
`moving_target` не требует точного предсказания траектории без модели.

Детектор пятна и LOS — разные вещи. Слабое пятно в коридоре не отменяет класс `visible_goal`.
