# Проверка утверждений аудита

Источник: исходные JSON (не перезаписаны) и код на момент фиксации.
Поведенческие поля двух каталогов (успех, тики, исход, причина, путь, смещение, miss, conf) **совпадают по всем 60 эпизодам**. Расходятся только `infer_ms` / `encode_ms`.

| утверждение | статус | основание | оговорка |
|---|---|---|---|
| baseline и memory дают одинаковые 23/60 | подтверждено | оба JSON: 23/60, исходы 23/16/21, причины 23/17/20 | это равенство артефактов, не независимое доказательство, что память «ничего не делает» вне этих 60 |
| восстановление в каталоге не активировалось | подтверждено | recoveries=0, detections=0 | юнит-тесты на искусственной стене срабатывают |
| GT-окон физической неподвижности нет | подтверждено | `gt_stuck_windows=0` | детектор GT смотрит команду+позу, не поток |
| u_trap/dead_end решаются простым поворотом к цели | подтверждено частично | 10/10, 0 столкновений | в JSON нет лога намерений; геометрия старта — лицом в торец, цель сзади; успех совместим с поиском-разворотом |
| скрытая или слабая цель лишает направления | подтверждено | obstacle/fence/corridor/weak: 0/5, conf≈0 или miss=1 | corridor: цель иногда в FOV, пятно ниже 0.12, bearing_err≈0.18 |
| narrow_gate проваливается при видимой цели | подтверждено | 0/5, miss 0.03–0.16, cause=control | v0: 33 столкновения; щель геометрически шире тела |
| vanish и дропы ломают курс | подтверждено | vanishing 0/5, latency 0/5 | vanish: miss=0 пока цель в учёте FOV; после hide цель не в FOV. latency: stale=4, не причина `stale` |
| два определения stuck | подтверждено | `EpisodeResult.no_progress` vs `_gt_stuck_windows` | исход эпизода `stuck` ≠ физическая блокировка |
| две линейки сценариев | подтверждено | `SyntheticEnv` (`open_field`…) vs `sim` (`open_goal`…) | разные CLI: `eval` vs `baseline-eval` |
| mock на другом энкодере | подтверждено | `build_mock_circuit` / `build_sck_circuit` → `ColorBlobEncoder`; оценка → `NavigationEncoder` | |
| польза потока в контуре не проверена | подтверждено | H15: сравнение не гоняли | F13 — разомкнутый bench, не политика |

Recall/precision в артефакте memory уже `null` при нуле окон, не 0. Это согласовано с требованием N/A.
