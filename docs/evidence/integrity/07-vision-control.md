# Диагностика зрение / управление

Привилегированный пеленг только если цель в FOV и есть LOS. Скрытая цель не подставляется.
Не входит в официальную оценку визуального агента.

Прогон: training v0, max_steps=200, `docs/evidence/integrity/07-vision-control.json`.

| сцена | A зрение+baseline | B эталонный пеленг+baseline | C зрение+oracle seek | вывод |
|---|---|---|---|---|
| open_goal | успех 173 | успех 137 | успех 82 | зрение достаточно; база рыскает |
| narrow_gate | провал, 33 столкновения | успех 164 | успех 97 | управление: избегание бьёт в створки; простой seek проходит |
| corridor | провал, miss=1 | успех 190 | провал, miss=1 | зрение: пеленга нет, задача проходима при эталоне |
| vanishing_target | провал | провал | провал | удержание курса: после hide пеленг пропадает и у B |
| single_obstacle | провал | провал | провал | цель с места не наблюдаема; эталон честно молчит |

Причину `vision` больше не ставить только по `miss_rate>0.40`. Смотреть цепочку: наблюдение → признак → намерение → команда → эффект.
