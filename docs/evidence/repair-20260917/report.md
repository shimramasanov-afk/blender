## Что исправлено

| дефект | изменение |
|---|---|
| Признак с кадра t сравнивался с GT после шага | оценка зрения по `frame_gt` до `env.step` |
| Укрытие считалось промахом детектора | `goal_observable` (LOS/FOV центра + кадр); `vision_miss_rate = null`, если оценивать нечего |
| Детекция восстановления без окна не была FP | одно окно — одна детекция; поздний tick внутри окна+допуск — TP |
| `recovery_time_p50` в тиках | секунды: `dt / tick_hz`; старые артефакты не менялись |
| Пропущенный кадр становился базой потока | stale обнуляет `_prev_gray`, чёрный кадр не сохраняется |
| HUD не маскировал пятно цели | `apply_profile` до серого и блоба |
| GT-блокировка по команде, не по применению | `applied_forward` + `previous_x/y`; отложенное действие не блокировка |
| Исчерпание попыток не отпускало бюджет | `consecutive_failures`; cooldown обнуляет счётчик |

Наблюдаемость оценщика — геометрический луч центра цели, не пиксельная разметка.

## Сопоставимое до/после (только шесть зондов)

Исходы эпизодов те же. Сдвинулись определения, не маршрут политики.

`net_displacement` теперь от стартовой позы, не от первого тика после шага.
`latency_drops`: пропуски больше не входят в знаменатель miss.
`single_obstacle`: нет доступных кадров цели, поэтому `mixed` и `null`, а не «детектор всегда ошибается».

Числа F14/F15 с этой версией метрик не сравнивать как одно измерение.
