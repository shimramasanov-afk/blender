# Visual sensor engineering

## Когда применять

Когда нужен новый зрительный признак или меняется `VisualEncoder`. Не применять, чтобы «улучшить зрение» без решаемого моторного вопроса.

## Входные данные

- Какое решение признак должен поддержать (пример: «цель слева/справа», «стена близко», «нет продвижения»).
- Синтетический рендер и, если есть, записанные кадры в репозитории.
- Бюджет времени на кадр (если неизвестен — измерить на стенде, не выдумать).

## Порядок работы

1. Определить, какое решение поддерживает признак. Одна фраза: вход политики или только диагностика.
2. Сделать простую эталонную реализацию (CPU, читаемые формулы).
3. Проверить на синтетических преобразованиях: сдвиг, поворот камеры, масштабирование, изменение освещения, окклюзия.
4. Добавить уверенность и обработку невалидности. Слабая текстура → низкая уверенность.
5. Проверить реальные записи, только если они есть в этом каталоге. Нет записей — шаг пометить `skipped`, не имитировать.
6. Сделать диагностическое отображение (маска/поле, сохраняется по флагу, не в синхронном пути политики).
7. Измерить стоимость (`preprocess_ms` отдельно от `infer_ms`).
8. Проверить пользу в замкнутом контуре против контроллера без признака. Без этого шага не заявлять пользу.

Особое внимание: движение камеры; маскирование HUD; интервал между кадрами; низкая текстура; окклюзии; свет.

## Проверки

- При нулевом dt или повторённом кадре признак не объявляет ложное движение без флага `stale` / `duplicate`.
- Поворот камеры на месте не равен продвижению персонажа в выходе признака.
- Нет потока ≠ нет препятствия: тесты со слабой текстурой и стеной.
- Признак не читает privileged-координаты среды.

## Результат

- Код эталона и, если нужно, более быстрый путь, сверенный с эталоном.
- Проверки в `tests/`.
- Диагностика и список провалов (когда уверенность обязана упасть).
- Число стоимости на согласованном размере кадра.

## Когда завершено

Есть эталон, тесты преобразований, поле уверенности и либо замкнутое сравнение, либо явная запись «контур не гоняли». Признак без уверенности не принимается в политику.
